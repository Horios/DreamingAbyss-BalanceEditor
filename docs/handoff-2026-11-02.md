### 曾出現的 `Running grep... Failed`

平衡器 repository 內沒有任何 `grep` 指令，原本也沒有 GitHub Actions。這個訊息來自當時執行者工具環境的搜尋步驟；`grep` 找不到符合字串時會以結束碼 1 結束，常被顯示為 Failed。與 Sites 登入無關。原始紀錄無法取得，無法進一步確認。

## 七、遊戲資料變更時的平衡器同步方式

```bash
EMBERWILD_GAME_ROOT=../Emberwild node scripts/sync-preview-editor-contract.cjs
EMBERWILD_GAME_ROOT=../Emberwild EMBERWILD_GAME_COMMIT=$(git -C ../Emberwild rev-parse HEAD) node scripts/build-online-runtime.cjs
node scripts/build-online.cjs && node --test tests/*.test.mjs tests/*.test.cjs
```

`sync-preview-editor-contract.cjs` 只同步 4 個固定共用模型；其他內嵌共用 script（`timed-boost-schema-v1`、`inventory-icon-model-v1` 等）需依 `tests/preview-compatibility.test.cjs` 的對照表，以遊戲檔案原樣替換。
