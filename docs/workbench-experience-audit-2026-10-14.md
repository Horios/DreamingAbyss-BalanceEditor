## 共同體驗

- 側欄搜尋涵蓋所有頁面、全域道具、角色、核心／輔助技能、地圖與怪物。道具／技能結果直接選到該筆設定；Enter 開啟第一筆，Escape 清除，向下鍵移至結果。
- 所有頁面新增目前位置、返回上一頁、驗證與發布入口。返回恢復選取與捲動位置；當前頁面、選取與展開分類會在同一瀏覽器保留。
- 長頁面提供區塊捷徑。維持既有篩選、排序、分頁與道具詳細跳轉；全域管理器局部更新後仍保留共同操作列。
- 本次變更／發布差異每列提供前往設定；把語意 diff 的 ID 解析成編輯器索引，支援精準選取職業技能、輔助技能、裝備與道具。不存在或未映射的資料退至原始 JSON。
- 頂列依實際高度調整固定側欄；小螢幕讓按鈕、表單、格線換行。增加停用狀態與鍵盤焦點，修正 checkbox 全寬。
- Ctrl/Cmd+S 立即儲存；離頁時補儲存尚未完成的工作區。

## JSON 草稿保護

未套用原始 JSON 獨立保存在瀏覽器，與有效的遊戲資料分開。切頁／重載會恢復文字；可下載原文字或確認捨棄。套用前維持完整既有驗證，驗證失敗不替換資料。若文字草稿建立後設計器資料已變動，套用前明確確認覆蓋。尚未套用時禁止驗證、建立發布摘要、提交發布及頂列匯出，避免使用者誤以為文字已生效。

## 發布操作

完整十步操作說明改為可展開說明，並保留所有文字。新增下一步提示與操作定位，版本說明在瀏覽器保留。建立測試摘要自行取得最新測試版，移除先取得版本才能點擊的重複步驟；不足四字或未授權時停用操作。確認發布須同時符合勾选、正式版文字、授權、有效摘要與非忙碌狀態。版本說明或資料更改後立即停用舊確認。正式版來源固定、摘要到期、衝突檢查、後端權限、還原與部署核對仍使用原機制。

## 驗證及限制

既有 46 項回歸加上 7 項體驗回歸；新增測試逐一開啟 42 頁、確認匯出資料沒有變動，並驗證搜尋／返回、JSON 文字保留、覆蓋衝突、發布確認與語意差異定位。

使用既有最小 DOM 進行資料流與控制項測試；兩個舊頁面需要補足 ID／data-key 選擇器模擬。這不是實際瀏覽器版面測試。目前環境沒有 Sites 所指定的 control-browser，依流程未啟動預覽或替換瀏覽器途徑，因此桌面／手機實際排版尚未瀏覽器驗收。此次未實際發布遊戲平衡資料，API 模擬與服務測試不代表新的真實 GitHub 上傳驗收。
