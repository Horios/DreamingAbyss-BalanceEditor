## 1. 分類與識別規則

1. 用途分級為主：道具 → 裝備／素材／消耗品 → 用途子類 → 詳細子類 → 道具。三大類都提供自己的細分，層級數按需要，不強迫每類深度相同。
2. 取得來源獨立：採集、煉金、商店、怪物是來源篩選，不是互斥的道具種類。另需容納現有分解、鍛造、任務／成就、信箱、初始配發等來源。
3. 同一識別碼只建立一份道具資料。多用途用標籤與反向引用顯示，多來源用多筆來源規則顯示，不複製道具。
4. 原料、加工材料、成品依實際用途分類。配方投入物不因用於煉金就被歸入「煉金產物」。
5. 道具模板與玩家裝備實例分開。品質、難度、階級、強化值是變體參數；BOSS 裝備生成規則保留，不為每件隨機掉落建立一個平衡道具。
6. 子分類可自訂、移動、改名；分類僅控制管理與顯示，不能暗中改變裝備職業限制、效果、數值或存檔鍵。
7. 固定 ID 與現有庫存入口必須保留；若後續更改名稱、ID、刪除或停用，需要引用與舊存檔檢查。名稱與程式類型不一致需顯示異常，不自行調整。

### 預留但目前沒有啟用道具的子類

消耗品 › 卷軸與票券 › 夥伴招募券：現有系統支援指定夥伴解鎖、招募價格、抽到／取得條件、重複券轉換金幣，但本次設定中的夥伴沒有 ticket 解鎖條件，因此現行清單為 0 筆。此分類要保留可擴充能力，不虛構具名道具。

其他未使用的武器類型（例如槌、祈禱書）按有效武器類型選項保留可擴充性，但不能假裝目前已有對應固定道具。

### 售價與分解的計算邊界

一般裝備、BOSS 裝備、夥伴信物必須都有售價與分解預覽。預覽可選品質、階級、難度、強化值；售價規則與分解規則分開。已有共用規則時提供繼承與精準跳轉；若增加個別覆寫，需在遊戲實際交易／分解流程讀取，且明確顯示影響範圍。

目前裝備售價依品質取 equipmentSellPriceByQuality；基本分解鍛鐵＝四捨五入［階級 ×（基礎鍛鐵＋品質 × 品質加成＋強化值 × 強化加成）］；粉塵＝四捨五入［基礎粉塵＋品質 × 品質加成］，再加該品質的額外產物。清單只記模板，實例強化值／品質不應被重設。

素材原本可售；一般消耗品已有各自售價。技能寶石目前沒有販售流程；其管理售價、販售資格與實際操作需一併規劃。招募券的「重複轉換金幣」與一般出售不能混為一談。

## 5. 取得來源與煉金素材的正確關係

| 來源 | 應設定／顯示的內容 | 精準跳轉目標 |
| --- | --- | --- |
| 採集 | 動作 ID、主產物／副產物、秒數、成功機率、數量、其他條件 | 指定採集動作或副產物 |
| 煉金／加工 | 產出配方、1～5 種投入材料與各自需求量、秒數、成功率、失敗消耗 | 指定配方；投入與產出分開列 |
| 商店 | 固定／隨機／生活材料商店、單价／份數、上架、抽取條件 | 具體商店商品規則 |
| 怪物 | 怪物 ID／地區／難度／普通菁英BOSS、掉落機率／量／條件 | 指定怪物與逐怪掉落規則 |
| 分解 | 來源裝備／品質、基礎公式、追加產物與數量 | 實際分解規則 |
| 鍛造 | 來源製作配方、材料／金幣需求、產出數量／裝備模板 | 指定 BOSS 或其他製作設定 |
| 任務／成就／信箱／初始 | 具體任務／成就／附件／初始配發設定；取得條件与量 | 相應來源設定 |

所有四種來源的材料都可以列入煉金材料候選，是否真正被消耗由配方決定。「可作為材料」與「目前有配方使用」要分開顯示。消耗品能否作為投入必須符合現有計數型庫存；裝備、信物與技能寶石不能僅靠分類變更就假裝能投入，若要支援須另補明確的選取與消耗規則。

範例：紅色草＝素材 › 製作材料 › 煉金與加工材料 › 自然原料，來源為採集，投入「加工紅色草」；紅色草泥＝加工材料，來源為加工配方，投入「煉製簡易治療藥水」；清水、藥水瓶＝液體／容器，來源為商店；簡易治療藥水＝消耗品 › 藥水 › 治療藥水，來源之一為煉金。

## 8. 實作順序與驗收條件

- 先完成分類模型：三大類完整子階層、自訂分類、用途標籤、依 stable ID 去重；把上述 328 個定義／變體納入。
- 再建立共通詳細頁：名稱／說明／圖示／色彩／售價／販售資格／來源／用途引用／庫存入口，新增及刪除做引用檢查。
- 逐類串接：一般裝備、BOSS 模板、信物、裝備成長材料、煉金材料、區域／BOSS 材料、寶石、藥水、票券、重鑄石。每個道具都能直接編輯或精準定位到實際設定。
- 補齊原本缺失的有效能力：新商店材料、鍛鐵／粉塵煉金庫存映射、必要的道具售價流程；未實作能力不得以無效輸入欄位充數。
- 更新各專屬頁的連結，保留共用規則的唯一資料來源；分類及圖示變更不得改玩法數值。
- 驗證 JSON 匯入匯出、來源改動即時同步、配方反向引用、效果真實生效、個別售價、分解預覽與實際產物、商店庫存、舊存檔、錯誤回滾、版本發布相容性；先更新測試版，正式版保留目前流程。

具體驗收範例：
- 紅色草只能有一筆，在採集來源可找到、煉金投入可選到；不因投入配方而顯示為煉金成品。
- 清水與藥水瓶屬素材的液體／容器，來源為商店；煉金成品來源不列它們。
- 簡易治療藥水屬消耗品，即使由煉金製造仍保持治療藥水的能力設定。
- 粉塵同時有強化／洗鍊／寶石合成用途，只有一份原庫存；加入煉金後消耗與其他用途一致。
- 主角裝備與夥伴信物都能查售價、能力與分解；任何「個別」設定需在實際交易中生效。
- BOSS 模板可定位普通／困難／地獄製作資料；素材的三種庫存鍵不合併。
- 技能寶石顯示鑲嵌與合成細節；出售能力與售價欄位狀態一致，不能只有表面數值。
- 在任一專屬頁返回全域管理器後，保留選取道具、子分類、來源篩選與未發布草稿。
