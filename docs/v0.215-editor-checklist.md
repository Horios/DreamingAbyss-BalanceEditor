## 七、發布流程

- 發布前執行第四節全部測試並與基準比對。
- 測試版發布只送出與線上快照不同的模組。確認一次只改一個欄位時，送出的模組與差異摘要正確，且沒有夾帶 `equipment/forms`、`world/drops`、`systems/shop`、`items/inventory-icons` 的舊內容。
- 發布到遊戲 `chatgpt-dev` 時，發布服務會遞增 `data/preview-version.json`（`server/release-service.cjs` 的 `nextPreviewVersion`）。確認新 commit 的版號正好比上一版多 1（遊戲 CI 的 `scripts/check-preview-version.cjs` 規則）。
- 發布後確認遊戲 GitHub Actions 的回歸閘門與 Pages 部署都成功，並讀回 `https://horios.github.io/DreamingAbyss/preview/data/build.json`，確認 commit 是發布產生的 commit。只看到 push 成功不算部署成功。
- 平衡器本身的部署（`.github/workflows/ci.yml` 與 Sites 部署）完成後，開啟線上平衡器，確認讀到的遊戲版本是 v0.215 以上。
